# SecuriFeed - PhishDetect


## About Project

SecuriFeed is a phishing detection web application that analyzes suspicious URLs and generates a risk score.


## Features

- URL Risk Score (0-100)
- HTTP/HTTPS Detection
- IP URL Detection
- Typosquatting Detection
- Suspicious TLD Detection
- Domain Parsing
- Threat Feed
- Phishing Awareness Game
- Learning Documentation


## Technologies

- HTML5
- CSS3
- JavaScript
- JSON


## Detection Methods

- Regex based URL scanning
- URL parsing
- Security rules
